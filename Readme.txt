# ToDoApp 📝

A sleek, intuitive, and efficient To-Do application built to help users organize their daily tasks, track progress, and boost productivity.

---

## 🚀 Features

* **Task Management:** Create, read, update, and delete (CRUD) tasks effortlessly.
* **Status Tracking:** Mark tasks as completed or pending with a single click.
* **Persistent Storage:** Keep your tasks saved even after refreshing the page or restarting the app.
* **Responsive Design:** Optimized for seamless use across mobile, tablet, and desktop screens.
